# `@editful/cli`

Create a React-ready Editful plugin project:

```bash
npx @editful/cli plugin new my-plugin
```

The package exposes the `editful` binary, so an installed copy can use the
shorter `editful plugin new my-plugin` form. Pass `--no-install` to create the
files without running the package manager, or `--npm` to use npm instead of
pnpm.
